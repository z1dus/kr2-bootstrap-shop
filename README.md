# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебную версию веб-сервиса **«No Pain, No Gain»** для составления программ тренировок и рационов питания под различные цели (похудение, набор мышечной массы, поддержание стабильного веса), разработанную с использованием фреймворка Bootstrap 5.
## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- локальное подключение Bootstrap CSS и JS Bundle;
- подключение `css/custom.css`;
- шапка страницы;
- Bootstrap-навигация;
- hero-блок на сетке;
- блок преимуществ;
- сетка популярных товаров;
- подвал страницы.

## Используемые технологии

- CSS;
